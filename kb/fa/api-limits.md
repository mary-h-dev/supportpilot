# محدودیت درخواست API
طرح Starter اجازهٔ ۶۰ درخواست در دقیقه و طرح Pro اجازهٔ ۶۰۰ درخواست در دقیقه را می‌دهد. محدودیت‌ها هر دقیقه بازنشانی می‌شوند.

وقتی از سقف عبور کنید، API خطای HTTP 429 و یک هدر Retry-After برمی‌گرداند که تعداد ثانیه‌های لازم برای انتظار را نشان می‌دهد. برای سقف بالاتر، دربارهٔ طرح Enterprise با تیم فروش تماس بگیرید.
